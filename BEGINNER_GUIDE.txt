BEGINNER GUIDE — Handwritten prescription reader (LLaMA-Factory)

============================================================
WHAT THIS PROJECT DOES
============================================================
Photo of a prescription → GLM-OCR (LLaMA-Factory) → text → drug matching.
A HUMAN must always check the answer.

Ollama is NOT used.

============================================================
WORDS
============================================================
OCR            = turn a photo into text
GLM-OCR        = the OCR model
LLaMA-Factory  = tool that serves and can fine-tune GLM-OCR
NER            = find drug names / dose / schedule after OCR
pipeline.py    = one command: OCR then NER

============================================================
FLOW
============================================================
  1. Start LLaMA-Factory API   (Terminal 1, keep open)
  2. Run pipeline.py           (Terminal 2)
  3. Check output\ files
  4. Pharmacist / doctor reviews

============================================================
SETUP (ONCE)
============================================================
  cd C:\Users\HP\source\repos\Handwrittenprescriptionreader
  python -m venv .venv
  .\.venv\Scripts\activate
  python -m pip install --upgrade pip
  .\.venv\Scripts\pip.exe install pillow requests rapidfuzz spacy pyyaml
  python src\llamafactory_train.py setup

============================================================
RUN
============================================================
Terminal 1:
  python src\llamafactory_serve.py

Terminal 2:
  .\.venv\Scripts\python.exe src\pipeline.py data\raw\Test1.png

Check:
  .\scripts\check_local_ocr.bat

============================================================
FINE-TUNE (GPU MACHINE)
============================================================
See finetune_glm\README.md

  python src\llamafactory_train.py prepare
  python src\llamafactory_train.py train --mode lora
  python src\llamafactory_train.py export
