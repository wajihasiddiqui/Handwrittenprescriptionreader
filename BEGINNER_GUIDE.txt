BEGINNER GUIDE — Handwritten prescription reader

============================================================
WHAT THIS DOES
============================================================
Photo → GLM-OCR (loaded in Python) → text → drug matching.
A human must always check the answer.

No Ollama. No separate OCR server needed.

============================================================
SETUP (ONCE)
============================================================
  cd C:\Users\HP\source\repos\Handwrittenprescriptionreader
  python -m venv .venv
  .\.venv\Scripts\activate
  python -m pip install --upgrade pip
  .\.venv\Scripts\pip.exe install pillow requests rapidfuzz spacy pyyaml

  python src\llamafactory_train.py setup

============================================================
RUN (ONE COMMAND)
============================================================
  .\.venv_finetune\Scripts\python.exe src\pipeline.py data\raw\Test1.png

Or:
  .\scripts\run_local_ocr.bat data\raw\Test1.png

First run loads the model (can take several minutes).
You should see: --- OCR (llamafactory-inprocess) ---
